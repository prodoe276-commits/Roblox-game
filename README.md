# Roblox-Development
This is how you make a Roblox Game.
First, you need to learn how to code.
If not you can still use stuff from the toolbox to develop games, but it won't be as effective.
The thing that draws attention to people the most is the UI, mechanics, flow of the game, and first looks, such as the thumbnail and description and also the amount of people playing your game.
Those are the things you are going to want to work on. After you do those things you should also look into adding more detail into the games.
After you are done scripting, adding details, improving your game overall, you want to try to make thumbnail. Make a good and appealing thumbnail.
Make a good description for the game that will attract more people.
This is a short guide on how to make a roblox game.
